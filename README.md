# Naruto Quiz

**Naruto Quiz** Naruto evrenini keşfetmenize olanak sağlayan eğlenceli ve bilgilendirici bir uygulamadır. Farklı oyun seçenekleriyle, Naruto dünyasındaki karakterler, takımlar, klanlar ve köyler hakkında farklı soru çeşitleriyle bilgi seviyenizi test edebilirsiniz. Hatırlayamadığınız yerde ipucu alabilir, rekabetçi moduyla dünya sıralamasındaki yerinizi alabilirsiniz. Oyun geçmişi ekranından skorlarınızı takip edebilir, hatırlamadığınız detayları yeniden öğrenebilirsiniz.

## Projede Kullanılan Teknolojiler

- **In-App Purchases**
- **Google Ads**
- **Gemini AI**
- **Firebase Authentication & Firestore**
- **Firebase Remote Config**
- **Google Cloud Functions**
- **Coroutines**
- **Live Data**
- **Retrofit**
- **Jackson Converter**
- **Dagger & Hilt**
- **MVVM mimarisi**
- **Lottie & Glide**
- **Navigation Component**
- **Room Database**

## Özellikler

- Naruto evrenine dair farklı kategorilerde sorular.
- İpuçları kullanarak daha fazla bilgi edinme imkanı.
- Rekabetçi mod ile dünya sıralaması.
- Oyun geçmişi ekranından skor ve performans takibi.
- Eğlenceli animasyonlar ve kullanıcı dostu arayüz.

## Kurulum

1. **Proje Klonlama**:
   ```bash
   git clone https://github.com/kullaniciadi/naruto-quiz.git
   ```

2. **Bağımlılıkları Yükleyin**:
   Gradle dosyasında gerekli bağımlılıkları ekleyin ve senkronize edin.

3. **Firebase Ayarları**:
   - Firebase Console'da bir proje oluşturun.
   - `google-services.json` dosyasını indirin ve `app` klasörüne ekleyin.

4. **Remote Config ve Cloud Functions**:
   - Remote Config parametrelerini Firebase Console üzerinden yapılandırın.
   - Kullanıcı kayıt olması ile 12 ipucu hakkı cloud functions ile sağlanmaktadır.

5. **Uygulamayı Çalıştırın**:
   Android Studio ile projeyi açın ve bir emülatörde veya gerçek cihazda çalıştırın.
